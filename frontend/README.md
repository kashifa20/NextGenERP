# NextGenERP frontend

This directory contains the React/Vite single-page application for NextGenERP. For prerequisites, local development, API proxy settings, and production deployment, see the project [README](../README.md) and [deployment guide](../docs/deployment.md).

Run `npm ci` to install the lockfile-pinned dependencies, `npm run dev` to start the local Vite server, `npm run build` to create the production bundle, and `npm run lint` to run Oxlint.
